# Citing & license

## Citing

If you use macro_candi in published work, please cite it. The repository includes a
[`CITATION.cff`](https://github.com/JurgenKriel/macro_candi/blob/main/CITATION.cff) file, so
GitHub's **"Cite this repository"** button (right sidebar) gives you APA and BibTeX.

```bibtex
@software{kriel_macro_candi_2026,
  author  = {Kriel, Jurgen},
  title   = {macro\_candi: quantitative analysis of Candida-macrophage
             lattice light-sheet timelapses},
  year    = {2026},
  version = {0.1.0},
  url     = {https://github.com/JurgenKriel/macro_candi},
  license = {GPL-3.0-or-later}
}
```

Please also cite the tools it is built on, in particular
[Cellpose](https://www.cellpose.org/) (Cellpose-SAM),
[skan](https://skeleton-analysis.org),
[napari](https://napari.org), and
[bioformats2raw](https://github.com/glencoesoftware/bioformats2raw).
